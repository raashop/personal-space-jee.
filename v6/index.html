How automatic sync works

  1. Update or load the latest youtube-tracker extension in Brave.
  2. Open a YouTube lecture, click the extension, paste this planner page's URL into Automatic planner sync, and click Connect planner once.
  3. Approve the browser permission for this planner site. That permission lets the extension send its lecture records to this page.
  4. When the planner stays open, matched videos update it live. When it is closed, records stay safely in the extension and catch up next time you open the planner. No repeated export/import.

The tracker uses video title and chapter keywords, not transcripts. It tracks YouTube in this browser; it cannot see lectures watched in the Android YouTube app or a different browser profile. Export is kept only as an optional backup.

Automatic tracking in Telegram Web

The Personal Space extension can detect a playable video in Telegram Web, record its playback time, and sync a matched lecture here. It works in Brave on the Telegram website, not inside the Telegram Android app.

  1. Update the Personal Space extension to version 1.3.0 or newer by loading the latest youtube-tracker folder.
  2. Open https://web.telegram.org/ in this same Brave profile and open the channel/post containing the lecture video.
  3. Play the video for 30–60 seconds. The extension's Telegram Web status should show whether it recognized the nearby caption/title.
  4. Keep this planner open. A recognized lecture with recorded watch time should appear below automatically. If the post caption doesn't name a chapter, use the manual form as a fallback.

The extension inspects the visible post text around the video only; it does not read private chats in the background or send your Telegram login/session data. Chapter matching is title/caption-based, so some posts may need manual matching.

Manual import fallback

If automatic detection cannot read a caption or match a chapter, paste the Telegram post link and lecture title below. We'll match it to the JEE syllabus and let you confirm before changing chapter progress.
